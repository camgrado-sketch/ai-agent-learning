JSON javascript object notation

● { } 大括号 代表一个”对象 object“，一个完整的产品

● \[ ]方括号 代表一个”列表 array“ ，比如一款椅子的可选色

● ： 冒号  用于连接名称和内容

● ，逗号 分隔 不同的属性

（对象组合object 和数组 array的区别：object 组合强调不同维度关系（例如长宽高）的数据的打包，array，同类平级数据的整合）



如果我把公司所有的产品目录都变成这种 JSON 格式，AI 就能一秒钟帮我筛选出“所有高度低于 750mm 且支持堆叠的椅子”。这比翻看 500 页的 PDF 目录要快得多。
