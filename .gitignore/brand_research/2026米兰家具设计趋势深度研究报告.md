# 一、趋势背景：从"产品竞争"进入"价值体系竞争"

米兰国际家具展（Salone del
Mobile.Milano）长期以来不仅是全球家具产品发布平台，更是观察未来生活方式的重要窗口。

进入2026年前后，全球高端家具行业正在经历一次价值重构。

过去十年，家具设计竞争主要集中于： - 形式创新 - 造型差异 - 快速迭代

但未来，高端家具品牌更加关注：

1.  材料真实性
2.  手工工艺价值
3.  长生命周期设计
4.  情绪体验
5.  品牌文化积累

家具正在从"物件"转变为一种生活方式符号。

------------------------------------------------------------------------

# 二、2026米兰家具设计核心趋势

## 1. Soft Minimalism 柔性极简主义

2026年的家具设计将继续弱化传统现代主义中过于理性的线条。

相比过去强调几何、效率和视觉秩序，新趋势更加关注：

-   身体包裹感
-   柔和比例
-   触觉体验
-   情绪安全感

沙发、座椅开始呈现更大的体量、更低的高度以及更柔软的边界。

代表品牌：

## B&B Italia

B&B Italia长期代表意大利现代家具工业体系。

其设计方向体现：

-   工业制造能力
-   高级舒适体验
-   现代生活方式

近年来品牌大量采用圆润结构、大尺度软包以及模块化组合。

代表产品：

### Camaleonda Sofa

设计师： Mario Bellini

Camaleonda重新定义了模块化沙发。

特点：

-   深座设计
-   独立模块组合
-   柔软视觉语言

它不仅是一件家具，更成为一种空间景观。

趋势意义：

未来家具不再占据空间，而是塑造空间。

# 三、品牌案例研究

# 1. Cassina：经典现代主义的新生命

## 品牌定位

Cassina是意大利现代家具的重要代表。

其核心价值：

-   设计历史
-   建筑师合作体系
-   高级制造工艺

合作设计师包括：

-   Le Corbusier
-   Charlotte Perriand
-   Patricia Urquiola

------------------------------------------------------------------------

## 设计趋势分析

Cassina近年来的重要方向：

### 1. 经典再设计

品牌并不是简单复制经典产品，而是通过：

-   新材料
-   新颜色
-   新生产方式

重新激活历史作品。

例如Le Corbusier系列，通过现代制造技术重新诠释20世纪现代主义家具。

### 2. 收藏级家具

Cassina体现未来趋势：

家具 = 设计资产

高端消费者购买的不只是功能，而是设计文化。

------------------------------------------------------------------------

# 2. Poliform：安静奢华体系代表

Poliform代表现代住宅高级定制方向。

设计语言：

-   克制
-   优雅
-   空间整体性

代表设计师：

Jean-Marie Massaud

------------------------------------------------------------------------

## 趋势分析

Poliform强调：

### 材料统一

常见组合：

-   木材
-   石材
-   金属
-   皮革

形成完整空间语言。

### 色彩趋势

未来高级住宅色彩：

-   沙色
-   米色
-   灰褐色
-   深棕色

避免强烈视觉刺激。

这与Quiet Luxury趋势高度一致。

------------------------------------------------------------------------

# 3. Karimoku Case Study：日本木工美学

## 品牌背景

Karimoku Case Study代表日本与北欧设计融合方向。

核心：

-   木工技术
-   自然材料
-   精密细节

合作设计师：

-   Norm Architects
-   Keiji Ashizawa

------------------------------------------------------------------------

## 设计语言分析

其家具特点：

### 轻盈结构

区别于意大利家具的大尺度厚重，日本家具强调：

-   细腿
-   精准连接
-   视觉轻量化

### 木材价值

木材不是表皮装饰，而是设计核心。

重点关注：

-   木纹方向
-   手感
-   表面处理

对于未来中国高端家具具有参考价值。

------------------------------------------------------------------------

# 4. Stellar Works：东方现代主义路径

Stellar Works代表亚洲高端家具品牌的发展方向。

核心优势：

-   酒店项目经验
-   定制能力
-   东方文化表达

合作设计师：

-   Neri&Hu

------------------------------------------------------------------------

## 设计趋势分析

其设计语言：

### 东方克制

不是传统符号化东方，而是：

-   比例
-   材料
-   工艺

体现文化。

### 商业空间应用

未来家具市场的重要方向：

住宅 + 酒店 + 商业空间融合。

家具品牌需要具备：

-   标准产品
-   定制能力
-   项目管理能力

-   情感化设计
-   材料实验
-   色彩创新

Mario Bellini代表意大利设计黄金时代。

经典设计仍然具有长期生命力。

------------------------------------------------------------------------

# Neri&Hu

Neri&Hu代表中国设计师进入国际家具体系的重要案例。

-   东方文化研究

证明中国设计可以通过文化和方法论参与全球竞争。

-   产品体系

-   品牌故事

## 3. 重视定制能力

# 总结

2026米兰国际家具展反映出的核心变化，并不是某一种颜色或者造型流行，而是整个家具行业价值逻辑的变化。

未来真正具有竞争力的家具品牌，将同时拥有：

-   对材料的理解
-   对工艺的掌控
-   对生活方式的洞察
-   对品牌文化的长期建设

家具设计正在从制造产品，走向创造价值。
