# 家具选品思维链模板

## 任务说明
请针对「具体场景」提供家具配置建议

## 思考步骤（必须按此顺序进行并输出思考过程）
1. **空间属性分析**： 分析该场景的使用频率、人流密度及核心功能。
2. **CMF 策略推导**：基于空间属性，推导出应采用的材料（如：易打理的面料 vs 高级皮革）和色彩基调。
3. **品牌基因匹配**：在 Arper，Viccarbe， Pedrali， Walter knoll 中选出最契合的 1~2 个品牌并说明理由。
4. **最终配置清单**： 给出具体产品名称及配置理由。

## 输出约束
- 严禁直接给出清单。
- 每一个步骤必须独立成段。
