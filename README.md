# AI Agent Learning Workspace

这是我的 AI Agent 学习仓库，用于记录 Track A — CLI Power User 的 10 周学习过程。

## 我的学习目标

我是一名专注 Contract 领域的家具产品设计师，希望通过 AI Agent 学习，逐步提升以下工作能力：

1. 更高效地进行国际家具品牌、产品体系与项目案例调研。
2. 将品牌研究、CMF 趋势、空间场景分析整理成可复用模板。
3. 学会使用 CLI Agent 辅助本地文件管理、资料归档与报告生成。
4. 探索 Obsidian、Eagle、本地文件夹与 AI Agent 的协作方式。
5. 最终建立适合设计调研与产品策略工作的 AI 协作流程。

## 当前学习路线

我优先学习 Track A — CLI Power User。

初步计划：

- Stage 0：Python、GitHub、CLI、JSON/API 基础
- Stage 1：LLM 基础、API、token、模型成本
- Stage 2：Prompt Engineering
- A1：选择并使用 CLI Agent
- A2：建立可重复使用的 CLI 工作流
- A3：将 CLI Agent 接入真实工作流程
